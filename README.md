# seunggulee1007/tap

Homebrew tap for [ReviewGate](https://github.com/seunggulee1007/reviewgate-for-claude-code) — review every change Claude Code makes, before it continues.

```sh
brew install --cask seunggulee1007/tap/reviewgate
```

ReviewGate updates itself from its banner, so `brew upgrade` leaves it alone unless you pass `--greedy`.
